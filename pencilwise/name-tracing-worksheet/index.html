How to use the worksheet

  1. Point to the green dot on each letter of the first row and trace the name together with your finger.
  2. Trace the dotted rows with a pencil, starting each letter at its top or at the dot.
  3. On the start-dot row, write each letter from its dot; on the blank lines, write the name alone.

The letters are drawn from the same stroke data as the app, so the shapes match the style you chose, including accents (é, ü, ñ, ł) in names.
