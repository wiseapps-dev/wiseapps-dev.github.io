How to tie an alpine butterfly knot

Alpine butterfly. A fixed loop tied in the middle of a rope, which takes load on the loop or along the rope in either direction. Climbers and mountaineers use it as a mid-rope loop. Both twists must go the same way: a wrongly tied one can look similar but slip or capsize.

Origin and references

Origin
The earliest known description is A. A. Burger's 1914 Iowa State bulletin, which called it a lineman's rider. Climbers know it from C. E. I. Wright and J. E. Magowan's 1928 Alpine Journal article, which named it the butterfly; Ashley listed it as the lineman's loop in 1944.

Every knot weakens the rope it is tied in, and any knot can slip or jam. Check it each time you tie it.

Common mistakes

  • Twisting the two eyes in opposite directions. Both twists must go the same way: a wrongly tied one can look similar but can slip or capsize.
  • Loading it before it is dressed. Pull the loop and both standing parts so every strand lies neatly.

See also
